# 真实题库导入规范

生产题库 `src/bank.json` 初始为空。21 套、630 题是收录目标，不代表已获得原文；未核实每年的套数，不生成虚构卷名或考题。2015–2024 年均可筛选。

## 工作流

1. 从原扫描件逐字转录意大利语题干和 A/B/C，不翻译替换原文。记录文件名、页码、题号或可核验 URL。
2. 双人或逐题核对原文及标准答案。未确认答案填 `null`；无中文解析填空字符串，不猜测。
3. 用 `npm run validate:bank -- /绝对路径/bank.json` 校验。
4. 页面「题库与设置 → 选择题库 JSON」导入到当前浏览器；或者将经审核的完整集合存入 `src/bank.json` 后重新构建发布，成为新安装的默认题库。
5. 已有用户不会被新发布内置库自动覆盖，需导入新版完整包以增量合并。

## JSON 格式

顶层：`{"schemaVersion":1,"papers":[],"questions":[],"errata":[]}`。
以下为字段说明，并非考题示例。所有 ID 是稳定的非空字符串。

| 集合      | 字段                         | 说明                                                                |
| --------- | ---------------------------- | ------------------------------------------------------------------- |
| papers    | id, year, title, source      | 真实试卷 ID、2015–2024 整数年份、真实名称、资料来源                 |
| questions | id, paperId, number          | 题目 ID、所属试卷 ID、1–30 原题号                                   |
| questions | textIt, options              | 意大利语原文；options 必须有非空 A/B/C 字符串                       |
| questions | originalAnswer               | 原始标准答案 A/B/C 或 null（待核验）                                |
| questions | answerSource                 | 答案来源；有标准答案时必须非空                                      |
| questions | explanationZh                | 中文解析字符串，待补充时为空                                        |
| questions | source                       | 原题出处，必须非空                                                  |
| errata    | id, questionId, answer       | 独立勘误 ID、题目 ID、修正后 A/B/C                                  |
| errata    | reasonZh, source, recordedAt | 中文原因、勘误依据、带时区 ISO 8601 时间（如 2026-10-23T12:00:00Z） |

导入包自身必须满足引用完整性：增量包中的题目带所属 paper，勘误带所属原题与 paper。重复导入相同内容幂等。原题及已有勘误记录不可覆盖；同 ID 不同内容会整包拒绝。补充解析也应由维护者核对后，通过明确的数据迁移发布；当前导入刻意不提供静默覆盖。导入前后均执行完整校验，失败不写入。

## 勘误与评分

原始答案永久保留；修正通过新增 errata 记录表示。同题多条修正按 recordedAt 最新者生效，同题同时间拒绝。时间是记录版本依据，导入前需审核。撤销勘误时新增一条恢复正确答案的勘误，不删除历史。

考试开始时冻结题目、有效答案和勘误快照。考试中不渲染答案/解析，交卷后一次评分。历史记录不随题库更新重算；错题本按最近一次作答结果整理。旧错题用当前有效答案复习，答对后移出。

每套恰好 30 道唯一编号题目且全部有有效答案才允许考试；部分转录的试卷可练习已有可评分题。每题一分，未答计错；未确认的官方时间和及格线不硬编码。纯客户端离线应用不是防作弊考试平台，开发者工具能读取本机题库。

`tests/fixture.ts` 中的 30 条合成数据仅用于测试软件，不会进入生产包，也不得用作真题导入。
